# 首次同步操作手册

> 最近更新：2026-08-02

## 前置条件

- 客户端已安装并启动（Source 与 Sink 可同一实例双角色）；
- 管理员账号已初始化（`MIC_SYNC_ADMIN_PASSWORD`）；
- 数据库账号按[账号权限手册](database-accounts.md)配置；
- 远程 Sink 端已生成 Sink 访问令牌（目标 Sink 实例「系统管理 → Sink 访问令牌」），并准备在「端管理」中粘贴。

## 步骤

1. **登录**：访问 `http://<host>:19090/`，使用管理员账号登录。

2. **端管理**：Source 端固定为当前实例；在「端管理」新增远程 Sink 端（或使用本地 Sink 端），
   填写访问地址与 Sink 访问令牌，点击「探活」回填实例 ID 与状态。状态为 `READY` 的 Sink 端才能被任务选择。

3. **配置数据源**：「数据源」页按所属端维护数据库档案：为本地 Source 端保存 Source 数据源，
   为对应 Sink 端保存目标数据源；点击「测试连接」确认产品名/版本与能力正常。

4. **新建任务**：「同步任务」→「新建任务」：
   - 选择 Source 数据源；
   - 选择就绪的 Sink 端，点击「获取 Sink 信息」加载目标数据源（Sink URL 与实例 ID 自动解析）；
   - 选择 Sink 目标数据源；
   - Table 模式完成读取配置（Schema/表/字段/分页 Key/更新时间字段）；SQL 模式填写单表只读 `SELECT` 并检查；
   - 填写目标表并完成字段映射（同名字段自动建议）、写入模式与唯一 Key。

5. **预检并启用**：进入「预检与提交」，执行预检；无阻断项后保存并启用。

6. **首次全量**：任务详情点击「首次全量」（自动含追赶）。

7. **验证目标数据**：在目标数据库核对目标表行数与内容。

8. **后续增量**：任务详情点击「手动增量」，从 Checkpoint 减 10 分钟回看窗口继续。

## 常见问题

| 现象 | 处理 |
|---|---|
| 校验报「目标表缺少唯一约束」 | 目标表创建主键/唯一索引，或改用 INSERT_ONLY |
| Sink 端状态非 `READY` | 在「工作台」查看未就绪原因；由 DBA 执行初始化 SQL（回执表）后重新检查 |
| 批次返回 401 / `SINK_AUTHENTICATION_FAILED` | 在目标 Sink 生成新令牌，并在「端管理」更新对应 Sink 端令牌 |
| 运行 `UNKNOWN` | 查询回执/安全重试；回执不可达时保持 UNKNOWN 并检查网络 |
| 任务删除失败 | 存在活动 Run，先暂停/终止 |
