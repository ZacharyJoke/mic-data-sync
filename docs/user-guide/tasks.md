# 同步任务使用指南

## 任务生命周期

```text
草稿 DRAFT → 已启用 ENABLED ⇄ 已暂停 PAUSED → 已禁用 DISABLED
                  ↘ 已阻塞 BLOCKED（结构漂移/能力不满足）
```

- 草稿可以随意编辑；
- 启用后读取定义、目标表、写入模式、唯一 Key 与字段映射被锁定，只能更新名称、Sink URL 与期望实例；
- 需要修改语义配置时，创建新任务版本并重新执行首次全量。

## Table 模式

- 选择 Schema、表与字段，支持 AND 条件、分页 Key 与更新时间字段；
- 必须配置组合后稳定唯一的 `paginationKeys`，优先使用主键或全部非空的唯一索引；
- 支持 20 行样例数据预览；
- 分页使用 Keyset 分页，不使用 OFFSET。

## SQL 模式

- 只支持单条、单表、只读 `SELECT`；
- 支持字段别名、CASE、CAST 和无副作用表达式；
- 不支持多表 JOIN、UNION、CTE、FROM 子查询、用户编写 LIMIT/OFFSET、DML/DDL 等；
- 无法解析的 SQL 可保存为草稿但不能启用；
- 支持 `SELECT *`，检查后可将结果字段展开为明确字段。

## 字段映射

- 同名字段自动建议映射，名称不同只推荐不强行映射；
- 支持「源字段映射 / 固定值 / 不写入」；
- “不写入”只允许用于可空、有默认值或自动生成的目标字段；
- UPSERT Key 只用于定位，不参与 UPDATE。

## 写入模式

| 模式 | 要求 | 说明 |
|---|---|---|
| `UPSERT` | 目标表存在主键/唯一索引 | 存在则 UPDATE，不存在则 INSERT；自动排除目标主键与全部唯一索引列 |
| `INSERT_ONLY` | 无唯一 Key | 追加写入；每个新全量 Run 前需由 DBA 准备目标表或明确接受重复风险 |

## 运行操作

- **首次全量**：全量读取 + 自动追赶；
- **手动增量**：从最后确认检查点继续，更新时间字段模式默认回看 10 分钟；
- **暂停/继续**：暂停后 Task 与 Run 保持占用名额，恢复后继续；
- **安全重试**：复用原 `runId/batchId` 与 Payload Hash，适用于结果未知或可重试失败；
- **终止**：删除任务前需先暂停/终止活动 Run。

## 与目标表相关的约束

- 工具不会自动创建、修改或删除目标业务表；
- 不传播 DELETE；
- 目标 SERIAL/IDENTITY/SEQUENCE 默认由目标数据库生成；
- 结构变化兼容时产生警告继续，不兼容时暂停并等待 DBA 恢复或人工保存新任务版本。
