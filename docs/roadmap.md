# 路线图

> 最近更新：2026-08-02

## 当前状态：MVP-I1 候选版本（0.1.0-SNAPSHOT）

已交付：端管理、多数据源、Table/SQL 任务、预检启用、首次全量/手动增量、批次幂等、暂停/继续/安全重试、Sink Token 轮换、结构化诊断、Linux x86_64 分发包。

## 近期（P1）

- 每日固定时间调度与 IANA 时区配置；
- 全局并发排队与更好的名额策略；
- INSERT_ONLY 跨 Run 重复保护；
- 目标表 DELETE 传播（受控模式）；
- 应用级备份/恢复 CLI；
- Webhook 通知；
- ARM64（Kylin V10 SP3 2403）正式认证；
- 三方向完整 E2E 与 4 小时稳定性基准验收；
- 回执自动清理与保护窗口管理；
- 目标数据库 Epoch/回退检测；
- Sink 身份重绑定与离线确认流程；
- 应用级自定义 truststore 生命周期管理；
- 专用最终切换向导。

## 中期（P2+）

- 多实例高可用、Sink 集群与自动选举；
- 双向/多向同步与冲突合并策略；
- Web JDBC 驱动上传与在线升级；
- 更细粒度的限速、监控指标与告警；
- 数据校验/对账能力。

## 明确不做

- CDC（变更数据捕获）、消息队列与分布式事务；
- 多表 JOIN 与任意复杂 SQL 自动同步；
- 自动创建、修改或删除目标业务表；
- 无需人工确认的全自动最终切换。

完整能力边界见 [docs/help/support-scope.md](help/support-scope.md)。
